# attic

Scripts moved here during the 2026-08 `scripts/` triage: each is unreferenced
from the README, docs, tests, benchmarks, workflows, or other scripts, but is
plausibly still useful (bench and diagnostics tooling for live engines, or a
deprecated helper superseded by a newer entry point). Nothing in the repo
invokes them; they are kept for manual use and recoverable history.

If you resurrect one, move it back up to `scripts/` first. Anything not
resurrected is a candidate for deletion in a future cleanup (`git log --follow`
works through the rename).
